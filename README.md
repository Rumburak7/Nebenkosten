# 🏠 Nebenkostenabrechnung

**Programm: Adam Bryks 2026**

Einfache Betriebskostenabrechnung für ein Mehrfamilienhaus, direkt im Browser.

**Seite:** https://rumburak7.github.io/nebenkosten/

## So geht's
1. **Haus & Wohnungen**: Vermieter-Angaben, Abrechnungszeitraum, Wohnungen mit Wohnfläche.
2. **Mieter**: Name, Wohnung, Personen, monatliche Vorauszahlung. Bei Ein- oder Auszug im Jahr das Datum eintragen; berechnet wird nur die Wohnzeit.
3. **Kosten**: Gesamtbeträge laut Rechnungen, Verteilerschlüssel wählen (Wohnfläche, Personen, Wohneinheiten, Verbrauch, teils Fläche/teils Verbrauch, direkt). Bei Verbrauch die Zählerwerte je Mieter eintragen.
4. **Ergebnis & Druck**: Nachzahlung oder Guthaben je Mieter und eine Übersicht. „Abrechnung drucken“ erstellt einen Brief je Mieter (auch als PDF speicherbar).

Leerstand (wenn eine Wohnung leer stand) trägt der Vermieter. Das Programm zeigt diesen Anteil getrennt.

**＋ Neues Jahr** übernimmt Wohnungen, Mieter und Kostenarten und leert die Beträge.

## Datenschutz
Alle Daten (Namen, Beträge) bleiben **nur im Browser auf diesem Computer**. Sie werden nicht ins Internet hochgeladen. Bitte regelmäßig **💾 Sichern**: Damit wird eine Datei im Ordner „Downloads“ gespeichert, die man mit **📂 Laden** wieder öffnen kann, auch auf einem anderen Computer.
